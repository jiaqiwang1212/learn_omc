**Key learnings / gotchas discovered:**

1. **torch_mlir.compile is removed** — the current API is `torch_mlir.fx.export_and_import`.
   The plan's exercise code used the old API. All scripts use the new one.

2. **export_and_import takes *args, not a tuple** — correct call:
     `tmfx.export_and_import(Matmul(), torch.ones(4,4), torch.ones(4,4), output_type=...)`
   NOT: `tmfx.export_and_import(Matmul(), (torch.ones(4,4), torch.ones(4,4)), ...)`

3. **export_and_import creates its own Context internally** — do NOT wrap in `with tmir.Context():`
   The function calls `ir.Context()` internally; wrapping causes double-context issues.

4. **linalg.generic indexing maps may be aliased** — in the emitted IR, maps appear as `#map`
   references defined at the top of the module, not inline in the op. Text parsing must handle
   both inline and aliased forms.

5. **torch.aten.matmul lowers to torch.aten.mm** — for static 2D tensors torch-mlir emits
   `torch.aten.mm` (not `torch.aten.matmul`) in TORCH dialect output.
